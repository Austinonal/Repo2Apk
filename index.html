แผนการแปลง

ใช้ได้กับ repo public ที่เป็นเว็บ (HTML/JS/PWA, React/Vite) ไฟล์ทั้งหมดยังไม่ได้เซ็นรับรอง ติดตั้งลองใช้เองได้ ถ้าจะขึ้นสโตร์ต้องเซ็นเอง (Android ตั้ง keystore ใน secrets ได้)

ตั้งค่า GitHub token

ดูแผนได้โดยไม่ต้องตั้งค่า แต่ตอนกดสร้างไฟล์ ต้องมี token ที่สั่ง build ใน repo ของเว็บนี้ได้ ตั้งครั้งเดียว

สิทธิ์ที่ต้องมี: Actions และ Contents = Read and write เฉพาะ repo นี้ token เก็บในเบราว์เซอร์เครื่องนี้เท่านั้น สร้าง token
