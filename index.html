เปลี่ยน repo เป็น APK

วางลิงก์ repo เว็บของคุณ ระบบจะบอกก่อนว่าจะตัดอะไร เพิ่มอะไร และแต่ละอย่างส่งผลกับแอปยังไง เมื่อคุณกดยืนยันแล้วจึงสร้าง APK

  1. ดูแผน
  2. ยืนยัน
  3. สร้าง APK

ตัวอย่างแผนที่คุณจะเห็น

แผนการแปลง

ตั้งค่า GitHub token (ทำครั้งเดียว)

ดูแผนได้เลยโดยไม่ต้องตั้งค่า แต่ตอนกดสร้าง APK ต้องมี token ที่สั่ง build ได้

token เก็บในเบราว์เซอร์เครื่องนี้เท่านั้น ให้สิทธิ์เฉพาะ repo นี้ตัวเดียว

ใช้ได้กับ repo public ที่เป็นเว็บ (HTML/JS/PWA, React/Vite) ได้ไฟล์ debug APK ที่ติดตั้งในเครื่องได้เลย แต่ยังอัปขึ้น Play Store ไม่ได้
